This Python project firstly asks you which browser you want to use (edge is also an option but im on mac Os so it doesn't show up). It then asks you which action you would like to do and finaly how many tabs/windows you would like to open. Once opened, the terminal displays your RAM usage after every opened tab/window.

You can add whatever url you want, the default one is wikipedia.
